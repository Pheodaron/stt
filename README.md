# STT demo

Go + gRPC. GigaAM распознаёт речь, Nemotron определяет говорящих, Silero находит речь и паузы.

[Карта проекта: код, обработка аудио и работа моделей](PROJECT_MAP.md).

Полная встреча: файл → PCM mono 16 kHz → интервалы спикеров → GigaAM → JSON.
Живой режим: Ogg/Opus-чанки → PCM → Silero → GigaAM → partial/message.

Модели входят в образ. При запуске скачиваний нет. Первая сборка требует доступ к GitHub, PyPI, PyTorch, Hugging Face и хранилищу весов GigaAM.

## CPU

Нужны Podman, podman-compose и mise:

```bash
mise run build:cpu
mise run run:cpu
```

Контейнер использует стандартную bridge-сеть без создания отдельной сети Compose. Опубликован только TCP-порт `${HOST_PORT:-8080}` → `8080`. Клиент подключается к `localhost:8080` при стандартных настройках. Настройки — в `.env`, пример — `.env.example`.

Публикация одного порта не запрещает исходящие соединения. Для запрета выхода контейнера в интернет нужны правила firewall хоста или платформы запуска.

## Расшифровать встречу

Нужен Go 1.25.1+:

```bash
go run ./cmd/stt-client -addr localhost:8080 -file meeting.wav -out result.json
```

Клиент загружает файл чанками и ждёт один полный ответ: текст, время, спикеры и пересечения.
В консоль выводится читаемая расшифровка: время, говорящий и текст; пересечения и вынужденные разрезы отмечаются отдельно.
Исходный JSON сохраняется в `-out` (по умолчанию `<аудиофайл>.transcription.json`), читаемый текст — рядом в `.txt`. Путь текста можно задать через `-text-out`.

Дополнительно создаётся `.merged.txt` с временем `ЧЧ:ММ:СС` (миллисекунды отбрасываются) и номерами говорящих без слова «Говорящий»: последовательные фрагменты одного говорящего объединяются в диапазон от начала первого до конца последнего, текст каждого фрагмента идёт с новой строки. Паузы входят в общий диапазон; смена говорящего, неизвестное авторство и одновременная речь разделяют реплики. Путь можно задать через `-merged-out`. Подробная `.txt` сохраняет все исходные интервалы сервера с миллисекундами.

## GPU

Нужны NVIDIA-драйвер и NVIDIA Container Toolkit с настроенным CDI:

```bash
mise run build:gpu
mise run run:gpu
```

GigaAM работает на GPU, Nemotron остаётся на CPU.

```bash
mise run logs
mise run stop
```
