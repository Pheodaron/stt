# ONNX Runtime C API header

Unmodified `onnxruntime_c_api.h` from ONNX Runtime v1.20.1 (C API 20):
https://github.com/microsoft/onnxruntime/blob/v1.20.1/include/onnxruntime/core/session/onnxruntime_c_api.h

MIT licensed, copyright Microsoft Corporation. See LICENSE in this directory.
The header is used only to check CUDA provider/driver readiness against the same
native runtime loaded by sherpa. Inference remains in the official sherpa Go API.
API 20 also works with newer ONNX Runtime releases through the versioned C API.
